# Demo run

Material from the first full run on the live site (2026-10-31), for the `/example` page and the demo video.

The three files now live in `frontend/public/demo/`, where the `/example` page loads them (`frontend/lib/example.ts` holds the brief and the four answers).

| File | What it is |
| --- | --- |
| `model-photo.png` | The shopper photo: a fictional person made with AI image generation, not a real person. |
| `haven-cardigan-tryon.jpg` | YouCam clothes try-on of Haven's Chunky oatmeal cardigan on that photo. |
| `haven-cardigan-video.mp4` | YouCam 5-second video made from the try-on. |

The brief was "Build a look around the Chunky oatmeal cardigan from Haven.", top size M, budget $200, sent from the cardigan's product page (`itemId: hv_chunky_cardigan`). Haven answered with the cardigan ($76) and the Suede pouch bag ($36), $112 in all; Northline, Mono Studio and Sol Social answered with their own picks.

The try-on took about 10 seconds and the video about 11 minutes.
