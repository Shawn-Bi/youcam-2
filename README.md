# Look Exchange — YouCam Hackathon

> Shoppers post a style brief; stores compete with personalized, shoppable virtual try-on proposals, previewed on the shopper's own photo and turned into a short AI video.
>
> 用户发布穿搭需求，商店用可购买的个性化虚拟试穿方案竞争，方案可在用户自己的照片上预览，并生成简短的 AI 视频。
