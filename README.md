## About the stores / 关于商店

The four stores in Look Exchange, and every product, price and size they offer, are **samples** made for this hackathon demo. They are not real shops, and nothing can be bought. The try-on previews and videos are generated by the YouCam API and show appearance only, not exact size or fit.

Look Exchange 中的四家商店及其商品、价格和尺码都是为本次黑客松演示制作的**示例**，并非真实商店，也无法购买。试穿预览和视频由 YouCam API 生成，仅展示外观，不代表精确尺码或合身程度。
